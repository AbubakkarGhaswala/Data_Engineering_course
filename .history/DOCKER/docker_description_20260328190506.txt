What is Container ? 
    So the container is a packege where it store the applications as well as it's dependencies 
    and configuration.
    it is very portable and it can share with anyone and anyone can easily use it. 
    it make development and deployment more efficient

Where Does Container Lives ?
    So all containers are live in DockerHub on DockerHub there more than 100000+ Container images are there.
    We can search it and install and use it.

Why Docker Container Is Usefull ?

        Before Container :- 
            we have a team of developer and we are working on same project which include 10 dependencies like js,mongodb,nodejs etc right and

What is Docker Image ?
    So The Image is a actual packege 
    inside the docker image there is an applications layer called container where all code files or dependencies are there 
    so the meaning of it is portable that we install a docker image and when we run that docker image then it run and create a 
    container environment.


Basic Docker Commands :- 
    docker pull [imagename] :- this command will help you to pull the image from docker hub 

    docker run  [image name]:- this will run container in attach mode which is bydefault

    docker run -d [image name] :- this will run container in detach mode where the container run in a background of terminal 

    okay for example we have one image and we want to use it's different version so what we just need to do is 
    docker run -d [imagename:version name] :- this will install that specific version

    okay now we have 2 same image but different versions and we want to use both in our 2 different applications so what we will do 
    we have to assign a 2 different port to both so how we can do so 
    docker run -p[port where we want to start : port which image have ] -d [imagename]

    docker start[container_id] :-this will gonna start your container 

    docker stop [container_id]:- this will gonna stop your container 

    docker ps  :- It will list out all running containers

    docker ps -a :- it will show you all running and stops container . basically it show history also like which containers we have used.
