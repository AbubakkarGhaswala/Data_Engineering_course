Why NoSQL — DynamoDB stores data as key-value pairs, not rows and columns like MySQL. So there is no fixed schema. Each item can have different attributes.
When to use DynamoDB vs MySQL — DynamoDB is for high speed lookups on large scale data. MySQL is for structured relational data with joins and complex queries.
